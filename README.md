# SOP 工具組

把一條天天在做、但沒人寫下來的流程，變成兩份看得懂的文件：
**給同事看的圖解步驟**，以及**給主管看的工時對照**。

單檔 HTML，**點了就能用**。不用安裝、不用帳號。
圖片和影片從頭到尾都留在你自己的電腦上，不會上傳到任何地方。

## 兩個分頁

### ① SOP 製圖

一步一張圖。圖片有三種進法：

- <kbd>Ctrl</kbd>+<kbd>V</kbd> **貼上**（截圖工具剪完直接貼，最快）
- 一次**拖一批**圖片進來
- **匯入影片**，播到關鍵畫面按 <kbd>M</kbd> 自己截

步驟之間有 `⊕`，點了就在那個位置插一張空白的，再把圖放進去 —— 跟投影片一樣。

每張圖都能加標記：箭頭、手指、游標、編號、框選、**遮蔽**（蓋掉客戶名稱、報價、個資）、放大擷取。
標記是疊上去的，**原始畫面不會被改掉**。編輯器預設是最常用的矩形；切到「選取」後，既有貼圖、
矩形、箭頭、標號與遮蔽都能再次選取、移動、縮放或調整端點，不必刪掉重畫。貼圖的尺寸控制點可往外
放大、也可往中心縮小；舊檔中尚未調整過大小的貼圖仍維持原本預設尺寸。

Windows 常用快捷鍵可直接用：<kbd>Ctrl</kbd>+<kbd>Z</kbd> 復原、<kbd>Ctrl</kbd>+<kbd>Y</kbd>
或 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> 重做、<kbd>Ctrl</kbd>+<kbd>C/X/V</kbd>
複製／剪下／貼上所選標記，以及 <kbd>Delete</kbd> 刪除。游標在文字欄位時仍是正常文字操作；
未複製標記時，原本用 <kbd>Ctrl</kbd>+<kbd>V</kbd> 貼 Windows 截圖的流程不變。畫箭頭、框選或遮蔽時按
<kbd>Esc</kbd> 會取消當下動作並回到「選取」，不會關閉編輯器；要離開請按右上角 × 或「取消」。

步驟註解若直接以 `1.`、`1、`、`-` 或 `•` 開頭輸入多行清單，書面版與簡報版會完整保留每一行；一般文字仍以第一行作為步驟名稱，其餘行作為說明。

**產出**：兩種版本，各自都能先**預覽**再決定要不要下載。

- **書面版（HTML）** —— 一步一塊、圖大字少，寄出去就能看；也能直接列印成 PDF，每一步不會被切到下一頁。
- **簡報版（16:9）** —— 一頁一步、滿版投影，用 ← → 翻頁、選單跳頁、按 <kbd>G</kbd> 看所有頁、<kbd>F</kbd> 全螢幕。開會要講的時候用這個。第一頁就是你的第一個關鍵影格，不會自動生封面 —— 要封面就自己標一格放在最前面。

**改回來**：這兩種 HTML 裡都存了**編輯資料和每一步的畫面**。之後按「開啟既有檔案」選那個 HTML（或直接拖進來）就能接著改，不必另外保管 `marks.json`，也不用重載影片就看得到圖。要重畫箭頭、換截圖的話再開原影片，工具會換回真畫面，當初那組標記也會一起回來。

> 2026-08 以前匯出的 HTML 沒有存這些資料，載不回來 —— 工具會直接告訴你「這份是舊版匯出的」。重做一次並重新匯出，之後那個檔案就能一直開回來改。

### ② SOP 工時紀錄

把步驟換算成工時，填「現況」與「AI 導入後」兩條流程，算出省下多少人時。

第一頁做好的可以按「**帶進工時紀錄**」直接帶過來 —— 步驟名稱、順序、截圖都會過去。
現況與 AI 導入後的卡片之間都有 `⊕`，可直接在那個位置插入步驟，不必從最下面新增再往上拖。
卡片裡的截圖也使用同一套可二次編輯的標註工具。

畫面上的成本換算統一採 **5 元／分鐘**。

**產出**：交件檔 `.sop.html`。

## 工時怎麼算

每個步驟讀起來就是一句話：

> 每次 **`dur`** 秒/分/小時（處理 **`qty`** 份），整條流程每 **`every`** 個 **`freq`**
> 跑 **`volume`** 次，**`hc`** 人處理。

```
月人時 = 每次秒數 × 次數 volume × 人數 hc × (該週期每月次數 ÷ every) ÷ 3600
月次數：日 20.8、週 4.33、月 1、季 1/3、年 1/12
```

**份數 `qty` 不進公式**，它只是記錄這一步每次處理幾份。「每次多久」量到的
本來就是處理完那幾份的時間，再乘一次份數會重複計算。

**最常見的錯誤是次數。**「一天花 2 小時做這件事」要填 `dur=2小時`、處理量 `volume=1`，
不是 `volume=176` —— 後者會讓工時暴增幾百倍。
算出來的數字如果跟體感差很多，先檢查處理量，不是公式。

**錄影量得到的只有「做一件多久」。** 一天做幾件、多久做一次、幾個人做，
錄影裡永遠看不出來 —— 那幾欄工具會留白，要你自己填或交給 AI 一起問。
用貼上的圖片做的，連「每件多久」都沒有，三欄都是空的。

## 給 AI 用

「匯出」裡的 ZIP 是**寫給 AI 讀的**。`標註稿.md` 開頭內建一段說明，
告訴 AI 怎麼解讀順序、耗時，以及截圖上的標記（框選＝重點、黑塊＝刻意遮蔽、
裁切圖＝只留了一部分），還會提醒它：

> 錄影只錄得到「做一件的樣子」。一天做幾件、多久做一次、幾個人做，
> 錄影裡看不出來，一定要另外問使用者。

把資料夾丟給 Claude 之類的助理，說「幫我把這份標註做成 SOP」就會接手。

## 環境需求

- **Chrome 或 Edge**（用到 `requestVideoFrameCallback`，截圖和時間戳才對得起來）
- 影片：mp4 / webm / mov，Windows 內建錄影（<kbd>Win</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd>）可直接用
- 純前端，無後端、無外部連線

## 已知限制

**貼上／上傳的圖片沒有存進草稿。** 影片截的圖關掉再開會從影片重抓，
但貼上的圖沒有來源可抓，重整分頁就會不見。做到一半請先匯出。

## 注意

送出交件檔之前**先看一眼截圖**。裡面是內部系統畫面，可能帶客戶名稱、料號、
報價或個資 —— 不該外流的地方用「遮蔽」蓋掉再匯出一次。
