# SOP 錄影標註器 · 使用說明

雙擊 `SOP標註器.html` 就能用。不用安裝、不用網路，**影片只在你這台電腦上讀取，不會上傳到任何地方**。

它不是剪片軟體 —— 不會剪、不會改你的影片。它只做一件事：
讓你在時間軸上標出「這裡是一個步驟」，然後把那一刻的畫面截下來、配上你寫的說明，
打包成一份 AI 讀得懂的東西。

---

## 三分鐘上手

### 1. 錄一段操作

Windows 內建：<kbd>Win</kbd> + <kbd>Alt</kbd> + <kbd>R</kbd> 開始錄，再按一次停止。
檔案會存在「影片 / 擷取」資料夾。用 OBS 或其他工具也可以，mp4 最保險。

**想邊做邊講解就開麥克風** —— 講解裡的「為什麼要這樣做」「這步常出錯」是 SOP 最值錢的部分。
不想講也沒關係，等一下用打字寫進註解一樣。

### 2. 把影片拖進標註器

拖到中間黑色區域，或點一下選檔。

### 3. 一邊看一邊標

播到要記錄的畫面，按 <kbd>M</kbd>（或按「＋ 標註這一刻」）。左邊就多出一個 block：
截圖、時間、以及一個空白的註解框。

**在註解框裡寫這一步在做什麼。** 第一行會變成步驟名稱，所以第一行寫短一點：

```
以料號在 TIPTOP 查廠商
要先切到採購模組，這個畫面每天要開幾十次
遇到新料號查不到，要去問採購
```

### 4. 在截圖上畫重點（選用，但很值得）

**點一下 block 的縮圖**，開啟截圖編輯器。四個工具，在畫面上拖曳就會畫出來：

| 工具 | 怎麼用 | 用途 |
|------|--------|------|
| ↗ **箭頭** | 拖曳 | 從空白處拉向目標，指出「要看的是這裡」 |
| ☝ **手指** | **點一下** | 指尖落在你點的位置。按住往外拖可以放大 |
| ➤ **游標** | **點一下** | 教學截圖裡常見的滑鼠箭頭，尖端落在你點的位置 |
| ① **標號** | **點一下** | 自動 1、2、3 排下去。同一步之內的操作順序用這個標 |
| ▭ **框選** | 拖曳 | 框住要注意的區域，例如某一欄、某個按鈕 |
| ▓ **遮蔽** | 拖曳 | 蓋掉不能外流的東西 —— 客戶名稱、報價、個資。**送出前務必檢查** |
| ⛶ **放大擷取** | 拖曳 | 框出一小塊，匯出時只留這塊並自動放大。畫面太滿、重點太小時用 |

畫錯按「復原」，或「清除全部標記」重來。**原始畫面不會被改掉** —— 標記是疊上去的，隨時能重畫。

為什麼值得花這一分鐘：Claude 讀截圖時會優先看你框起來的地方，遮蔽的黑塊它也知道是刻意蓋的、不會追問。
比你在註解裡打字描述「畫面右下角那個欄位」快得多，也準得多。

### 5. 順序錄錯了就拖

抓 block 左邊的數字往上下拖。**左欄由上到下就是最後輸出的流程順序。**
拖過之後上方會出現黃色提示，告訴你順序已經跟影片時間先後不一樣了 —— 這是正常的，
就是為了這個才做這個功能。想還原按「依時間重排」。

### 6. 匯出

按右上角的 **「輸出給 AI」**，彈出的窗會先給你一份摘要（幾個標註、幾個有截圖、幾個還沒寫註解），
然後按 **「下載 ZIP」**。存到「下載」資料夾，解壓縮就是一個叫 `<影片名>_標註` 的資料夾。

旁邊那顆「直接寫進資料夾」是進階選項，會跳系統的資料夾選擇窗。**Chrome 會擋掉某些資料夾**
（跳「資料夾中包含系統檔案」），遇到就直接用 ZIP，結果一模一樣。

### 7. 交給 Claude

把資料夾拖給 Claude，或直接說：

> 這是我標好的錄影，幫我做 SOP：D:\...\螢幕錄影_標註

接下來 Claude 會讀你的標註與截圖，跟你確認件數、頻率、AI 導入後怎麼做，
最後產出交件檔並問你要不要上傳。

## 快捷鍵

| 鍵 | 作用 |
|----|------|
| <kbd>空白</kbd> | 播放 / 暫停 |
| <kbd>M</kbd> | 在目前位置標一刀 |
| <kbd>←</kbd> <kbd>→</kbd> | 倒退 / 快進 1 秒 |
| <kbd>Shift</kbd> + <kbd>←</kbd> <kbd>→</kbd> | 5 秒 |
| <kbd>,</kbd> <kbd>.</kbd> | 逐格微調（找準確的那一格用） |
| <kbd>1</kbd>–<kbd>9</kbd> | 跳到第 N 個標註 |

游標在註解框裡時快捷鍵不會作用，可以放心打字。

## 幾個好用的地方

**標晚了兩秒？** 兩種修法：把時間軸上的釘子拖一下，或把影片播到對的位置後按 block 上的「⟳ 對齊」。
兩種都會自動重抓截圖，而且**你畫的箭頭、框、遮蔽會留著** —— 標記存的是比例座標，換張畫面照樣貼在同一個位置。

**長影片？** 右下角切 2× 速度掃過去找重點，標的時候再切回 1×。

**每一格上面的時間** 就是這一刀落在影片的第幾秒，點「跳到」會回到那裡。

**關掉再開？** 標註的時間點與註解會自動存在瀏覽器裡。下次載入**同一個影片檔**就會自動接回來（截圖會重抓，等幾秒）。
但這只存在這台電腦的這個瀏覽器 —— 標完請盡快匯出。

**改到一半想繼續？** 兩個檔案各載一次：

1. 「開啟影片」選原本那支錄影
2. 「載入標註檔」選資料夾裡的 `marks.json`（也可以直接把它拖進畫面）

順序反過來也行 —— 先載標註檔的話，它會告訴你要開哪一支影片。
如果標註檔跟目前開著的影片對不上（檔名不同），它會先問過你再套用。

## 匯出的資料夾長什麼樣

```
標註稿.md              ← Claude 讀這份：順序、時間、停留秒數、你的註解
marks.json             ← 程式讀的，也是下次要繼續編輯時載入的檔
shots/
  01_t000012.jpg       ← 每個標註點一張，檔名帶秒數
  02_t000031.jpg
  ...
```

勾了「一併存入原始影片」的話，影片也會包進去 —— **只有要做口述逐字稿才需要**（預設沒勾）。
影片動輒幾十 MB，包進去打包會變很慢。

## 標多少才對

一步大約 3–8 步是常態。判準是：**換了工具、換了系統、或換了一個人做，就是新的一步。**

- 標太細（連「按存檔」都標一刀）→ 步驟會碎成 20 條，反而看不出重點
- 標太粗（整段五分鐘只標一刀）→ 中間跨了四個系統，AI 沒辦法知道要接哪些

在同一個畫面連續做完的事情，算一步就好。

## 常見狀況

**影片放不出來 / 一片黑**
瀏覽器不認這個編碼。用小工具轉成 mp4（H.264）再試。錄的時候選 mp4 最保險。

**截圖看起來糊糊的**
標註器會照原始解析度截（最寬 1920）。如果原始錄影就是縮放過的，那截出來就是那個品質。
錄影時盡量用原生解析度，畫面上的字 AI 才讀得到。

**按「匯出資料夾」跳出奇怪的錯誤**
某些瀏覽器不支援直接寫資料夾，它會自動改用 ZIP。下載後解壓縮，效果一樣。

**不小心關掉分頁**
標註點與註解有自動存。重開、載入同一個影片就會接回來。
但「自動存」只是保險，不是備份 —— 正式的保存方式是匯出。
